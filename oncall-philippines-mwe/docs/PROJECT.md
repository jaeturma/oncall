# Project Definition

## Name
Oncall Philippines

## Purpose
A secure service-finding platform for urgent, same-day, and scheduled real-world assistance.

## Primary users
- Service Finder
- Service Provider
- Admin
- Accounting
- Budget
- Cashier

A user may eventually be both Service Finder and Service Provider.

## Main public journey

Guest:
Search → View anonymized providers → Sign in/register

Verified Service Finder:
Search → View provider → Request service → Provider accepts → Booking confirmed → Job → Completion → Rating

## Search UX

Landing:

- What help do you need?
- Where do you need help?
- Find Help

No mandatory category + service + province + municipality four-field form.

Results can later refine by municipality and service.

## Trust model

Both Service Finder and Service Provider should be verified according to admin-configured requirements.

Verification claims must match actual verification performed.

## Platform protection

Bookings, agreements, relevant messages, job status, agreed amount, payment status, reports, and incidents must be recorded inside Oncall.

## Emergency boundary

Oncall is not a replacement for official police, fire, medical, rescue, or emergency response.
