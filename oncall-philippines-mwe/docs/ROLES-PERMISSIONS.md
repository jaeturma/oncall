# Roles & Permissions

## Service Finder

Can:
- manage own profile
- search
- view allowed provider profile data
- create service request when eligible
- manage own requests/jobs
- rate provider after completion
- report provider/job
- view sponsored users
- view own commissions/wallet
- request withdrawal

Cannot:
- verify own account
- change sponsor arbitrarily
- approve own withdrawal

## Service Provider

Can:
- manage provider profile
- select services
- toggle availability
- respond to requests
- progress assigned jobs
- rate Service Finder after completion
- report incident
- view sponsored users/commissions/wallet if applicable
- request withdrawal

## Admin

Can:
- manage account types
- manage service catalog
- verify users/providers
- assign sponsor
- assess registration fee
- manage enforcement
- view audit/reporting
- configure commissions

Admin must not silently rewrite posted financial ledger entries.

## Accounting

Can:
- review wallet history
- validate withdrawal
- return/reject/recommend approval

Cannot:
- budget approve
- disburse

## Budget

Can:
- approve/reject/return accounting-cleared withdrawal

Cannot:
- disburse

## Cashier

Can:
- view approved withdrawals
- record disbursement
- upload proof/reference
- complete disbursement stage

Cannot:
- accounting review
- budget approve
